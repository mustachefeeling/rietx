# The sample absorption factor, refined by TOPAS on a synthetic bank

**Synthetic input, no measured data.** The pattern is the recovery pattern of
`tests/test_tof_absorption_factor.py`: Si on the fixture bank of
`tests/test_tof_corrections.py` (DIFC 12000 µs/Å, TZERO −5 µs, 2θ 90°, GSAS
type-1 profile α1 0.45, β0 0.055, β1 0.003, sig1 300), generated by rietx with a
sample absorption factor A_B = 0.10 Å⁻¹ and Biso = 0.46 Å², Poisson noise from
seed 20261127, 8000–45000 µs at 20 µs. Issue #1867.

| file | what it is |
|---|---|
| `generate.py` | `inp_text()` is the input TOPAS ran; `python generate.py OUT` writes both inputs and the pattern `si_synth.xye`, which is not vendored |
| `01_Si_noAB.inp`, `02_Si_AB.inp` | the inputs, LF line ends (TOPAS was given CRLF) |
| `01_Si_noAB.out`, `02_Si_AB.out` | TOPAS's refined output for each, CR stripped |

The second input writes the Rouse et al. (1970) cylinder factor into
`scale_pks` at µR = A_B·λ, with the coefficients `rietx.model.absorption`
states; the first has none. Both refine the scale, a four-term Chebyshev
background, the cell edge and Biso, with the calibration and the profile held at
the generating values, which is the protocol of the rietx fits in the test.

**The program:** TOPAS-64 Version 6 (c) 1992-2016 Alan A. Coelho, as its console
reports, run as a black box with `tc.exe`. No TOPAS file was read beyond what
TOPAS writes as its output. **The date:** 2026-11-27.

What TOPAS returned, and rietx on the same pattern (`test_tof_absorption_factor.py`,
darwin/arm64, `[dev,jax]`):

| arm | quantity | TOPAS | rietx |
|---|---|---|---|
| with A_B | A_B (Å⁻¹) | 0.10008(58) | 0.100085(65) |
| with A_B | Biso (Å²) | 0.46126(438) | 0.46007(49) |
| with A_B | Rwp | 2.275 % | 0.228 % |
| without | Biso (Å²) | −0.22411(1045) | −0.2233(318) |
| without | Rwp | 10.866 % | 10.644 % |

TOPAS's Rwp on the arm with the factor is ten times the noise, and its esds are
larger by about that factor. That residual is TOPAS's profile, not the factor:
it truncates each convolution exponential at 1e-3 of its height
(`tests/data/tof/topas_synthetic/README.md` measured ~1e-3 of the maximum), and
on a pattern of 2e4-count peaks that is far above the counting noise. The test
holds rietx to TOPAS within one TOPAS esd on A_B and on Biso, on both arms.
