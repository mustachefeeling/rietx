# rietx 1.0.1

A metadata and documentation release. No source file changed: `git diff
v1.0.0 v1.0.1 -- src/ examples/` is empty, so 1.0.1 computes what 1.0.0
computed and every number in
[VALIDATION.md](https://github.com/yue-here/rietx/blob/main/docs/VALIDATION.md)
still stands as measured.

## What changed

- **The packaging metadata and `CITATION.cff` were corrected.** The
  repository URL is the contact route for both. A release is the only way a
  metadata correction reaches the PyPI project page, since PyPI does not
  accept a re-upload of a version already published.
- **History from the 1.0.0 release work onward was rewritten.** Every commit
  from that point has a new SHA, and the `v1.0.0` tag moved to the rewritten
  commit. If you have a clone from before 2026-08-17, reset it:
  `git fetch origin && git reset --hard origin/main`. Signed merge commits
  are unaffected: the rewrite was scoped to the range it had to touch, so no
  signature was stripped.
- **The README was rewritten** in the project's documentation style, with the
  same sections. Two claims were corrected against the tests they quote: ten
  real-data acceptance suites rather than nine, and a QPA worst case of
  1.39 wt%.
- **`ATTRIBUTION.md` renders as one table again.** A blank line between the
  PANalytical `.xrdml` row and the Rigaku `.rasx` row ended the table early,
  so the last five format-specification rows showed as literal text on
  GitHub. Nothing in the repository renders that file, which is why no test
  saw it.
- **Fundamental-parameters profiles, neutron and time-of-flight data, and
  spherical-harmonics texture are described as planned for v2.** The manual
  called them "deferred, not planned", which contradicted the roadmap: the
  seams they need are already in the forward model.
- **The manual's machine-facing notes are titled "For agents"** rather than
  "For automated callers".

## Upgrading

Nothing to do. `pip install --upgrade rietx` gets the corrected metadata and
the new README; there is no behavioural difference, and no contract version
moved.
