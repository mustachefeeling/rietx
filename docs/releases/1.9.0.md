## New

- `TetherRestraint` and `AntiBumpRestraint` join the `Restraint` union (schema 0.50).
  A tether holds two atoms within a maximum distance, and an anti-bump keeps them beyond a minimum.
  Each row is zero on its flat side, as TOPAS's `Distance_Restrain_Keep_Within` and `Keep_Out` are.
  `rietx.model.restraints.anti_bump_restraints(phase, min_distance)` builds the anti-bump rows for every close pair and image (WP-1809, #888).

- `SequentialRefinement.forward_`: under `direction="both"`, the forward
  chain's `SeriesResult`, set before the backward walk starts, so a run can be
  judged at the halfway point (WP-1317, #218).
- `SeriesResult.moved_paths(n, min_sigma)`: the paths that moved most against
  their own esds, ready for `SeriesResult.plot`. It reads the new
  `SeriesResult.relative_paths` and `.angle_paths` (schema 0.51), which a run
  now records.
