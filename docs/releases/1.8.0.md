## Upgrading

Code written against 1.7.0 runs unaltered.

## Changed

- The matplotlib floor drops from 3.10.5 to 3.10 on Python 3.11 to 3.13.
  Python 3.14 keeps 3.10.5, the first release with wheels for it.
  Google Colab preinstalls matplotlib 3.10.0 and imports it at startup.
  Under the old floor, `%pip install rietx` upgraded it and Colab asked for a
  runtime restart before the tutorial's next cell.

## TOPAS files

- `write_topas_inp(..., p1_expand=True)` beside `free=`, `scale=`, `instrument=` or `pattern=` writes every copy of a site as an equation over the parameter it copies, so the P 1 file refines as the model does (#721).
  In 1.7.0 that combination was refused, and a bare `p1_expand=True` file, which still holds every value, is unchanged.
  `p1_expand="auto"` restates only a phase TOPAS cannot name (a k ≠ 0 supercell, an untabulated family group, a non-standard setting) and reports `TOPAS_PHASE_RESTATED_IN_P1`.
- With `instrument=`, a phase with a magnetic-only width is written as two `str`, the nuclear part and a `mag_only` magnetic part carrying the width, the form `read_topas_inp` merges back.
  1.7.0 refused it by name; a file without `instrument=` still names it, `TOPAS_FIELD_NOT_WRITTEN`.
