# API: everyday calls

This page lists the calls a refinement session makes, with each signature, its fields and the first line of its docstring.

Everything is reached as `rx.` after `import rietx as rx`.
`help(obj)` prints a call's full docstring.
Calls for one technique, such as magnetic refinement or another program's files, are on [API: techniques](api-techniques.md), and every other exported name is on [API: everything else](api-types.md).
