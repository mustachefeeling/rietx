# Parameter map

This page lists every parameter rietx can refine, grouped by what it does to the pattern.

Each row gives the dot-path a stage's `turn_on` glob matches, then the unit, the default and a range to check a refined value against.
A path with no default takes its value from the model you load.
The groups are a reading aid, so a path keeps its schema spelling and a group heading is not a glob.
