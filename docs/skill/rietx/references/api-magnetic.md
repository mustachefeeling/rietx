## An unknown magnetic structure

`rx.solve_magnetic` is the same closed loop one subject over: on a converged **neutron** fit with unexplained intensity, it proposes a propagation vector, candidate models per k, one trial refinement per class the powder cannot separate, and a ranked list with a stated criterion — never Rwp (more amplitudes always fit better), so classes inside the tie width abstain together rather than name a winner. Refuses a non-neutron histogram by name; everything else, "nothing here to solve" included, is reported. Provisional: the criterion may still move.

- `rx.solve_magnetic(refinement, data, *, phase: int = 0, sites: Sequence[str] | None = None, species: Sequence[str] | None = None, ion: str | dict[str, str] | None = None, g: float | dict[str, float] | None = None, k=None, top_k: int = 3, d_min: float = 1.5, magnitude: float = 2.0, plan: RefinementPlan | None = None, nuclear_group: str = 'parent', generator=None, tie_width: float = 6.0, tie_r: float = 0.02, k_trials: int = 2, k_tie_width: float = 10.0, cif_dir=None) -> MagneticSolution` — Determine a magnetic structure from a converged nuclear fit, or abstain.
