## How v1.7 is getting here

### An authored refusal, not a raw traceback (1337, closed 2026-10-03)

Two failures an outside campaign found (#244, #246) now fail in words. A
`tie()` whose implied value leaves a declared bound refuses as the other tie
refusals do: it names the tie, the value, the atom and the bound, and
registers nothing. A Pawley `summary()` and `suggest()` no longer die in a
numpy broadcast. The contributor's PR #537 also fixed a state bug nobody had
reported, a failed `tie()` leaving its tie registered. It shipped in 1.6.0.

### The Le Bail alternation has a stop rule (1323, closed 2026-10-03)

A Le Bail fit is a loop of partition and refinement, and the skill used to
send every Le Bail job to a hand loop with no cap. `fit` now runs the loop
itself under `RefinementPlan.lebail_passes`. It keeps the best pass, stops
when a pass comes back worse or at a fixed point, and names which pass it kept
with each pass's Rwp in `LEBAIL_ALTERNATION_STOPPED`. On issue #210's shapes
the exact cell keeps pass 1, a 0.3 % error converges, and a 2 % error wanders
and the best pass is kept. A run of passes is one job to `rietx watch` and the
GUI, a cancel part-way leaves the best pass standing, and the cap survives the
`.rxt` document. It shipped in 1.6.0. A background left at a seed that is too
low lowers Rwp, so no Rwp rule can see it; that is WP-1542.
