## How v1.8 is getting here

### A width freed at zero starts inside it (1930, in flight)

A stage that freed a softplus width on its floor left it there or not by
rounding, so the same tree reached χ²_red 12.48 on Linux and 9.69 on macOS on
LaB₆ + cBN with every assertion green (issue #832). The package now starts such
a row at 1e-3 of its unit and records it in `StageResult.seeded`, and the
LaB₆ + cBN protocol holds its Gaussian triple. That fit reaches 10.1518 on both
platforms. Fits that free `instrument.profile.y` from its default move; the
staged notes list what. A 0.05° seed was measured and refuted: it broke nine
suites whose true width is zero.

### A GSAS Gaussian width checked against GSAS-II's own peaks (1543, closed 2026-10-10)

1.7.0 read GSAS's Gaussian `U V W` as a variance. This release checks that
against GSAS-II's drawn pattern rather than its formula. GSAS-II's refined
LaB₆ widths, written as an `.instprm` and read back, draw 24 isolated lines
within 0.21 % of GSAS-II's own FWHM. The reading before #705 drew them 0.42 to
0.53 times as wide. The 8 ln 2 now has one definition, in `caglioti.py`. A
`.prm` offering several profile functions is read by `profile_set=`.

### 1.7.0 cut and published (1546, closed 2026-10-09)

The first weekly cut. It carried 89 pull requests over the five days after
1.6.0 and completed no milestone. Rigid bodies shipped as a provisional first
piece, the maintainer's call. The notes were rewritten from the tag range: the
staged file missed about 28 changes, mostly an outside contributor's, and six
of its claims were false on the tree. The cut re-measured every figure the
validation page, the manual and the skill quote, and about 70 had gone stale
with every check green. It found the Windows pre-upload gate red for four
nights on three tests that need a POSIX sandbox, fixed before the tag. The
measured ship block is the [v1.7 record](v1.7.md)'s appendix. The figures the
cut could not re-run are named in 1546's handover.

### The CIF writer on one registry (1319, closed 2026-10-09)

Issue #756's first three chunks. The six COMCIFS dictionaries are vendored for
tests, and a registry test checks every tag the four CIF writers emit against
them. One number rule writes a value without an esd as its shortest
round-tripping text, and refuses non-finite numbers and whitespace in a label.
Every CIF now opens with one structure block that names its setting three ways,
writes U, and states formula, Z, Mr, density and volume. A checkCIF baseline on
four public files, posted on #756, showed the consistency tests silent for want
of an operation loop. After the change, every structure-block alert is gone and
the computed and reported values agree on all five blocks. A 113-character
`_atom_type_scat_source` was found to stop PLATON without a word. The pattern
block, the multi-block layout and the validation hook went to 1933, the magCIF
parent record to 1911 and the XYZ importer to 1813.

### A planning-doc PR runs only what reads it (1506, closed 2026-10-09)

A PR that changes only planning documents now goes green in about two
minutes, down from about 20. It runs the four test files that read those
documents, found by an audit hook over one fast run rather than by grep.
Branch protection gates on two checks, `lint` and `ci-ok`, so the test matrix
can change shape without touching protection again. Every code PR's fast legs
now upload per-test timings, and each handover quotes what its added tests
cost. The cut to CI time those timings were collected for became WP-1547.
In the week to 2026-10-09 the median fast leg rose from 21.7 to 31.1 min,
mostly from three files. Dropping from four test workers to two on 10-07
changed nothing, because the runner has two physical cores.
