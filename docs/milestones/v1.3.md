# v1.3 — agents and programs

**Opened 2026-08-28** (version → `1.3.0.dev0`), the day v1.2 shipped. The
slot was queued the same day; free-standing peaks (1101-1103) shift to v1.4
and keep their numbers, the precedent v1.1 and v1.2 both set.

## Scope

The agent-facing surface refactored against two measured runs rather than
intuition — `../ROADMAP.md` § v1.3 states the evidence and the seven WPs, and
each WP file carries its own baseline. Nothing is restated here.

## Acceptance

**The rows were not declared when the milestone opened.** `../ROADMAP.md`'s
v1.3 row carried `—` from 2026-08-28 to ship, so these six are written at the
end from what the eight WPs measured, and that is weaker evidence than a bar
set in advance: a row written after the fact cannot fail. They are recorded in
this shape anyway because the alternative is a milestone with no statement of
what it was for, and because each one names a number a later session can
re-measure. The suite behind them is the [ship
appendix](#appendix--acceptance-at-ship-2026-08-30).

- **One integration surface, and it is the python API** — **met** (1303).
  `rietx.agent` is deleted rather than deprecated, on measurement: four traced
  rounds — 235 instrumented interpreter starts, a 91-call ramp run, a
  contributor's four projected runs and the same contributor's 5 430-call
  bundle — recorded **zero** calls of the JSON envelope from any agent that had
  a choice. It also could not carry its own case: patterns rode inline, so one
  lab pattern is ≈11 k tokens and a 68-pattern series ≈754 k in a single
  request. Nothing that computes moved; the five answer types serialize byte
  for byte.
- **A result says whether it is done, and why** — **met** (1302, 1305).
  `RefinementResult.__str__`, `Refinement.summary(deliverable=)` and
  `SeriesResult.summary()` answer in one call, numerical heuristics first and
  the visual check named rather than substituted. Measured against the ramp
  campaign's own `show()` loop: 35.2 kB per fit — which that harness truncated
  to a 2 kB preview — is 3.5 kB from the `HIGH_CORRELATION` dedup and cap
  alone, and `print(result)` on the same fit is 3.1 kB carrying more. §4b gained
  the deliverable the ramp run actually had, **a parameter against a series
  axis**, naming four `SEQUENTIAL_*` codes and `PHASE_UNCONSTRAINED` as
  stopping criteria for the first time; `suggest` says whether a parameter
  *pays* (`CandidateGroup.delta_bic`), and a flagged discontinuity checks
  itself against an independent cold pair at **+5 %** of a 68-pattern chain,
  every flagged step reproducing at **1.00**.
- **A phase the data cannot see is held, not bounded** — **met** (1301).
  Measured on the ramp's 13 sub-onset patterns through the agent's exact call:
  2164 iterations and a cell 14.9 Å from truth unbounded, 1342 and 0.163 Å with
  the bounds that agent added by hand, 1669 and **no cell reported at all**
  here — because a held parameter leaves `RefinementResult.parameters`, so a
  trajectory of a phase that appears part-way through starts at the onset.
  Support is re-measured at the answer and moves both ways, in one extra solve
  and never a third.
- **The protocol is a skill, and it documents its own doors** — **met** (1304,
  1308). `docs/AGENT_PROTOCOL.md` had reached 144 427 B, 2.2× what an agent's
  Read returns in one call, so an agent that tried to load it got lines 1-707
  and the 99-row diagnostics table never reached context. It is now a
  `SKILL.md` read whole (31 968 B of a 32 000 B cap, no cap raised) with nine
  reference files loaded on demand, in [an open
  format](https://agentskills.io/specification), in the wheel, committed at
  `.agents/skills/` and `.claude/skills/`, and installed by `rietx skill
  --install`. Its API index is **generated** from the installed package, and a
  **derived** gate now relates the skill's documented surface to the package's
  free verbs — which justified itself on its first run by naming **four**
  undocumented entry points where the WP was written for two.
- **An interchange format a pipeline can dispatch to** — **met** (1306).
  `rx.read_recipe` / `rx.write_recipe_tables` speak the PowderLine
  `GSASII_Rietveld` recipe. Every unit was measured against the reference
  output committed beside each recipe rather than adopted from the format's
  prose, and the one row the format states two ways (`Zero`, centidegrees in
  one module and degrees in another) is **refused** rather than picked. On the
  two-phase cathode this package lands **11-93 ppm** from TOPAS on all five
  free cell parameters, at Rwp 7.333 % against 7.326 %.
- **The block is measured, not asserted** — **met** (1307). Round 1.1: eight
  cells over two episodes and two models, $38.39. **Seven of eight runs stopped
  on a §4b deliverable row**, against **zero** in the 86-run baseline campaign,
  and every reel cell made WP-1305's three checks as package calls where the
  baseline agent made them by hand. The round also produced the two defects
  1308 then closed, and corrected its own leading finding three times — twice
  about framing, once against the code.

- **2026-08-29** — [1306](../wp/1306-powderline-recipe.md) shipped: `rx.read_recipe`

**The Windows job had been red for a day and the release gate is the Windows

it is UTF-8 rather than `errors="replace"`: a document is handed over whole or
not at all, and `K?` in an instruction an agent will follow is a corruption
rather than a degradation. Reproduced on macOS through `PYTHONIOENCODING`,
which is what makes it a guard rather than a Windows-only story.

**A golden masked the version's release phase and called it the view's shape.**
