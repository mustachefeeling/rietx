# v1.3 — agents and programs

**Opened 2026-08-28** (version → `1.3.0.dev0`), the day v1.2 shipped. The
slot was queued the same day; free-standing peaks (1101-1103) shift to v1.4
and keep their numbers, the precedent v1.1 and v1.2 both set.

## Scope

The agent-facing surface refactored against two measured runs rather than
intuition — `../ROADMAP.md` § v1.3 states the evidence and the seven WPs, and
each WP file carries its own baseline. Nothing is restated here.

## How v1.3 is getting here — the rolling narrative

- **2026-08-28** — opened with the version bump; `../ROADMAP.md`'s milestone
  row and CLAUDE.md's "today" sentence follow it. Next: WP-1301.
- **2026-08-28** — [1301](../wp/1301-hold-unsupported-phase.md) shipped: a
  phase the data cannot see is **held** for the stage rather than bounded, its
  scale left free so it can still appear, and `StageResult.held`/`.released`
  record what happened. The WP as filed covered only the phase that is
  invisible when the stage *starts*, which is not the case the in-situ ramp
  hit — `phase_support` measures the modelled contribution, so a phase seeded
  at scale 1e-4 is visible at stage start whatever the specimen holds, and the
  flat direction opens only as the solve drives that scale to nothing. So
  support is re-measured at the answer and moves both ways: a phase that
  appeared is released and the stage re-solved, one that collapsed is put back
  where the stage found it and held. One extra solve covers either, never a
  third, and the restore is licensed by the measurement that licensed the
  hold. Measured on the ramp's 13 sub-onset patterns through the agent's exact
  call: 2164 iterations and a cell 14.9 Å from truth on `main` unbounded, 1342
  and 0.163 Å with the bounds that agent added, 1669 and **no cell reported at
  all** here — a held parameter leaves `RefinementResult.parameters`, so a
  trajectory of a phase that appears part-way through starts at the onset.
  `SCHEMA_VERSION` 0.10 → 0.11. Three rules entered CLAUDE.md's flat-direction
  invariant, and the WP's log has the rest. Next: WP-1302.
- **2026-08-29** — [1302](../wp/1302-error-is-documentation.md) shipped: a
  wrong name now answers with the right one everywhere the two measured
  campaigns hit one — `Base.__getattr__` across all 134 schema subclasses,
  `Stage`/`RefinementPlan`'s own hand-written version, and a derived (not
  typed) top-level re-export of every public schema class, so `Source`,
  `EmissionLine`, `BackgroundChebyshev` and the rest stopped being named
  throughout the manual while unimportable. `HIGH_CORRELATION` deduplicates
  across a plan's stages and caps at 10 per fit; `progress=` on
  `fit`/`refine_sequential` writes one line per stage boundary, implemented
  as an `events=` subscriber, never a second channel. And a result now prints:
  `RefinementResult.__str__`, `Refinement.summary(deliverable=, plot=)`,
  `SeriesResult.summary()` answer "done or not, and why" in one call —
  numerical heuristics first, the visual check named but never substituted.
  Measured on the ramp campaign's own `show()` loop: 35.2 kB per fit (the
  harness had truncated it to a 2 kB preview) is 3.5 kB on today's code from
  dedup/cap alone, and `print(result)` on the same fit is smaller still
  (3.1 kB) while carrying more. `str(result)`/`summary(deliverable="qpa")` on
  11-BM NAC: 12/28 lines, frozen as a masked golden text. Next: WP-1303.
- **2026-08-29** — [1303](../wp/1303-retire-refine-json.md) shipped: `rietx.agent`
  is deleted — `refine_json`, the five request types, the `{ok, error}` envelope
  and the exported JSON Schemas — and there is now **one** integration surface,
  the python API, with `model_dump(mode="json")` as the wire and a raised
  exception where the envelope carried a code. It goes on measurement, not
  taste: four traced rounds recorded zero calls of it from any agent that had a
  choice, and it could not carry the case it was built for (patterns inline, so
  a 68-pattern series is ≈754 k tokens in one request). `SCHEMA_VERSION`
  0.11 → 0.12, the first step on that ladder to remove rather than add; the
  answer types it wrapped are untouched and serialize byte for byte. Two things
  the WP file did not predict, both decided against its letter. The manual
  chapter is **rewritten, not deleted** — it also documents `capabilities()` and
  the six version strings, so deleting it would have dropped live names out of
  the manual-API partition and broken ten cross-references — and the eval
  harness's JSON shim now **runs the request itself**, because that envelope was
  always the eval protocol's contract rather than the package's. The acceptance
  grep was sharpened from "no mention" to "no live use, every survivor
  identifiable as history": a pre-registered round's records are not rewritten
  when their result lands, and this retirement *is* their result. Next: WP-1304.
- **2026-08-29** — [1304](../wp/1304-protocol-as-skill.md) shipped: the
  operating protocol is an **Agent Skill** — `docs/skill/rietx/`, a `SKILL.md`
  read whole and nine reference files loaded on demand — in the wheel,
  committed at `.agents/skills/` and `.claude/skills/`, installed elsewhere by
  `rietx skill --install`, published at `rietx.org/skill/rietx/`. The cap
  decided the shape: the WP's own body was ~39.5 kB against a 32 kB limit, and
  the rule that resolved it is **a lookup leaves the body, a rule and its
  decisive number stay**. A review against the plan then found what the first
  cut had satisfied by the letter: the API index was names without signatures
  (the campaign's errors were signature errors), a test claimed to check names
  it never reached, and an installed skill named twelve manual chapters and
  three repository files by paths no install has. So the index is **generated**
  from the installed package and pinned byte for byte, the body's own field
  names are walked through the types, and the manual is reached by URL.
  `SCHEMA_VERSION` 0.12 → 0.13 for `capabilities().skill_path`. Full suite on
  the tree before the review 3558 passed / 131 skipped, exactly +33 on 1303.
  Next: WP-1305, whose fourth deliverable row lands in a body with ~400 bytes
  of headroom.
- **2026-08-29** — [1305](../wp/1305-series-deliverable.md) shipped: §4b now
  answers "good enough" for the deliverable the 2026-08-26 ramp run actually
  had — **a parameter against a series axis** — and for the first time names
  `SEQUENTIAL_PATH_DEPENDENT`, `SEQUENTIAL_PERSISTENT_FINDING`,
  `SEQUENTIAL_DISCONTINUITY` and `PHASE_UNCONSTRAINED` as stopping criteria
  rather than as messages. They print from
  **`SeriesResult.summary(deliverable="series")`**, decided against the plan's
  own assumption: a caller of `refine_sequential` holds no `Refinement`, and no
  single pattern carries a `SEQUENTIAL_*` row, so `Refinement.summary
  (deliverable="series")` answers with where a trajectory is decided instead.
  Two of that agent's hand-run checks became package calls. `suggest` carries
  `CandidateGroup.delta_bic` — the same gain read as model selection, since
  leverage never said whether the parameter *pays* at 22 000 channels — and
  `Refinement.summary()`'s `next:` line is that number rather than WP-1302's
  "run suggest" placeholder (0.71 s for the whole view on 11-BM NAC, one
  Jacobian build). The shipped form is `report.layer2.delta_bic` at the
  Gauss-Newton prediction, not the WP's literal `gain − k·ln N`, which is that
  expression only where the probe's χ²/N is 1 — the assumption the noise floor
  one gate over already refuses. And `verify_discontinuities=True` refits a
  flagged step's two patterns cold and independently, writing the cold step
  over the chain's to the diagnostic's `value`. Measured on the ramp run's own
  protocol, its 68 recorded patterns: chain 11.6-12.0 s against 12.1-12.2 s
  with the check, **+5 %**, and every flagged step reproducing at **1.00** —
  including the real transition at 430 → 440 °C. The false step the decision
  rule was written against no longer exists: under WP-1301 the CaF₂ cell is
  held in 40 of 68 patterns rather than walking, so the "the chain made it"
  direction is pinned on canned refits in the suite and **not claimed as
  measured on data**. `SCHEMA_VERSION` 0.13 → 0.14 for a *required*
  `delta_bic`, the one field in 1.3 a stored 1.2 answer does not validate
  against. The §4b row was paid for rather than granted: 31 593 → 31 876 B of
  32 000, with the QPA and resolution-limited evidence compressed to its
  decisive numbers and the `rietx compare` pointer moved beside the §8.1 rule
  it cites. Next: WP-1306.
