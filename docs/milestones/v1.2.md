# v1.2 — the GUI for a crystallographer

**Opened 2026-08-25** (version → `1.2.0.dev0`). The slot was drafted as
"free-standing peaks" (1101-1103); those WPs shift to v1.3 and keep their
numbers, the precedent v1.1 set when the speed series took its slot (and on
2026-08-28 to v1.4, when the agent-surface work was queued as v1.3).

## Scope

wrote notes. Three read-only passes over `gui/src`, `src/rietx/gui` and the
docs guards found a concrete cause in code for every note; each cause is one
WP (`../ROADMAP.md` § v1.2). The register of the notes, the cause, and the
verdict:

Decisions taken at the opening, with the user: help is cursor-only with a
click popover and no visible mark; a project without a CIF is two WPs (a
typed cell, then pattern-only projects); a ~3.2 MB example set ships in the
wheel; chips are non-interactive facts (the space-group adopt chips become
buttons); the hover tooltip becomes a readout strip. Two rules enter
`gui/CLAUDE.md` at the opening: GUI prose is written under
`/yue-docs-style`, and a button's `title=` is a verb phrase while every other
explanation is a corpus entry.

## Acceptance

Each row is checked by the WP that owns it, on the final tree, and quoted
here at ship with venv and platform:

- **One control vocabulary**: the style test (`gui/src/lib/style.test.ts`)
  green; the header shows at most three control geometries (1201).
- **One help mechanism**: no `title=` on a non-button element (vitest);
  every parameter family, flag, stage field and wizard field has a corpus
  entry (`tests/test_help.py`); the glossary builds `-W` (1202, 1203).
- **A project from nothing**: from a blank state, open a project by
  browsing, create one without the CLI argument, create one from a typed
  cell and one with no structure, all in a browser pass (1204-1207).
- **The plot holds still**: the measured table in WP-1212 shows zero axis
  change on hover and on an exclude drag, one react per drag.
- **The Model panel is the editor**: vary flags set there land as
  `set_vary` nodes; an instrument profile round-trips save → load (1214);
  a typed coordinate on a special position is refused with the free
  direction named (1215).
- **The manual is guarded**: routes partitioned, panel names in a corpus,
  screenshots generated, the glossary the one description authority; the
  beta declaration lifted (1017).

The shallow diagonal the maintainer reported — a fork from a node ten rows up drawn as one Bézier across the whole gap — is not a drawing problem: a tip-following lane pass frees a lane the moment its node is drawn, so a later fork could be handed a lane an edge was still travelling down, and a line that must cross ten rows *has* nowhere to run. `layout` now assigns lanes to **arcs**, one parent→child edge holding its lane from the parent's row to the child's, and with the span reserved `edgeSegments` steps sideways in exactly one row. Which end it steps at needs no second rule: the edge leaves the lane that goes on without it, so a fork crosses in the row below its parent and a merge in the row above its child. Lanes take an OKLCh hue rotation, five at 72° because that is the spacing at which the pair distance clears the phase palette's 0.13 floor at `--lane-c` and 60° does not — half the palette in each place, the rotation in `lib/history.ts` and the lightness and chroma in `app.css`, with `test_gui_palette.py` doing the arithmetic, since `structure3d._oklab_distance` is the one distance this package has. The other half: `toPrecision` chooses fixed or exponential per *value*, so one parameter family came out at two widths and a decimal point shared a column with a mantissa. Each family now declares its own place count, keyed by `rietx.help.PARAMETER_HELP`'s own globs and crossed against `help_keys.json` both ways so a new family fails until it is given one, and the **formatter keeps the column's width** — a rendering too long for its places falls back to exponential — which is why the three widths are stated once in TypeScript and handed to the CSS with no arithmetic to cross. The difference is given twice, absolute and as a percentage of |a| at three significant figures, because a cell length moving 12 ppm is a refinement result and `0.00%` is not a way to say it. One design line was struck rather than implemented: **no esd is reachable in a history diff** — `RefinementTree.diff` reads values off a `ParameterTable` built from each node's stored schemas, and a node holds state, not statistics — so the place count is the whole answer and not the fallback. Three defects came out of Chrome and none was reachable from jsdom, two of them one fact: **`ch` is the element's own zero**, so a `--text-xs` header sat inside its own tracks by a growing offset (1266/1341/1420 against the body's 1252/1335/1417) and a `Δ` cell without `mono` widened its track by a further 4 px — the family and the size belong on the row. The third: a percentage of a *signed* `a` disagrees with its own difference, measured on a Caglioti V refining −0.0002 → +0.0024, which printed `+0.002601` beside `-1.30e+3%`. Two smaller things the browser settled: only a **second** parent is dashed now, since dashing both of a merge's edges put three dashed rows down the middle of the trunk once the runs were vertical, and the background polynomial takes three places rather than exponential, its six coefficients on the FAP example running 159 to −15 where `-1.5321e+1` is a worse way to write −15.321. One claim withdrawn on the way: `.better` had been on every compare row with a non-zero delta, which says a parameter moved in a good direction; green now belongs to the Rwp badge alone. Measured (`[dev]`, darwin/arm64): a 12-node fixture with a six-row fork, a merge and a second fork — 12 edge paths, every crossing one row, compare columns right-aligned at 1252/1335/1417/1492 on every row including the header, no overflow at a 559 px sidebar and 34 px of it at 380, where the row side-scrolls and the path is the column that gives; vitest **572 → 583**, `svelte-check` 378 files 0 errors, `test_gui_palette.py` 10 → 15 and the fast python selection **3206 passed / 122 skipped** with no new skip; `gui/CLAUDE.md` 962 → 995 lines with its reason beside the cap.
