# v1.2 — the GUI for a crystallographer

**Opened 2026-08-25** (version → `1.2.0.dev0`). The slot was drafted as
"free-standing peaks" (1101-1103); those WPs shift to v1.3 and keep their
numbers, the precedent v1.1 set when the speed series took its slot.

## Scope

The maintainer used the GUI the way a first-time crystallographer would and
wrote notes. Three read-only passes over `gui/src`, `src/rietx/gui` and the
docs guards found a concrete cause in code for every note; each cause is one
WP (`../ROADMAP.md` § v1.2). The register of the notes, the cause, and the
verdict:

Decisions taken at the opening, with the user: help is cursor-only with a
click popover and no visible mark; a project without a CIF is two WPs (a
typed cell, then pattern-only projects); a ~3.2 MB example set ships in the
wheel; chips are non-interactive facts (the space-group adopt chips become
buttons); the hover tooltip becomes a readout strip. Two rules enter
`gui/CLAUDE.md` at the opening: GUI prose is written under
`/yue-docs-style`, and a button's `title=` is a verb phrase while every other
explanation is a corpus entry.

## Acceptance

Each row is checked by the WP that owns it, on the final tree, and quoted
here at ship with venv and platform:

- **One control vocabulary**: the style test (`gui/src/lib/style.test.ts`)
  green; the header shows at most three control geometries (1201).
- **One help mechanism**: no `title=` on a non-button element (vitest);
  every parameter family, flag, stage field and wizard field has a corpus
  entry (`tests/test_help.py`); the glossary builds `-W` (1202, 1203).
- **A project from nothing**: from a blank state, open a project by
  browsing, create one without the CLI argument, create one from a typed
  cell and one with no structure, all in a browser pass (1204-1207).
- **The plot holds still**: the measured table in WP-1212 shows zero axis
  change on hover and on an exclude drag, one react per drag.
- **The Model panel is the editor**: vary flags set there land as
  `set_vary` nodes; an instrument profile round-trips save → load (1214);
  a typed coordinate on a special position is refused with the free
  direction named (1215).
- **The manual is guarded**: routes partitioned, panel names in a corpus,
  screenshots generated, the glossary the one description authority; the
  beta declaration lifted (1017).

## How v1.2 is getting here — the rolling narrative

- **2026-08-25** — opened. The triage session wrote 1201-1217 and re-scoped
  1017; no code changed. Next: WP-1201.
- **2026-08-25** — [1201](../wp/1201-gui-house-style.md) shipped: one token
  layer and nine control registers in `gui/src/app.css`, `gui/CLAUDE.md`
  § House style as the vocabulary, and `gui/src/lib/style.test.ts` as the
  guard. Measured on the final tree: `font-size` declarations 69 across 15
  files → 34 across 10, seven literal sizes → the three tokens, eleven files
  declaring `.small`/`.tiny` → none. The plan named eight registers; `.pick` —
  a button that has given up its box because the row is the target — was
  written out by hand in four panels and had to be named, or the style test is
  satisfied by dropping `button` from a selector. Applying the vocabulary was
  not tidying: a multi-phase model's phase nav drew every phase in the primary
  register, so nothing showed the selection; the 3D viewer's four view buttons
  were four primaries in one row; and a chip and a pill each *contained* a
  button. A browser pass found three more that jsdom structurally cannot see,
  all cascade — a state selector keeps every property a more specific rule does
  not restate (every tab strip rendered as a segmented group),
  `text-transform` inherits into a button, and two panels put a size back at
  the call site through `font: inherit`. Given up on purpose: `⚠ not a fit yet`
  no longer routes to the Report tab, because a chip is a fact and does not
  act. Next: WP-1204.
- **2026-08-25** — [1202](../wp/1202-help-corpus.md) shipped: one place where
  a name is explained, and 87 explanations in it. Before this nothing in the
  tree said what a refinable parameter *is* — not the profile width terms, not
  the displacement parameters — and the GUI's only help was hover text kept in
  two hand-maintained TypeScript lists. `src/rietx/help.py` now holds 33
  parameter families over 44 globs plus six named arms, each crossed against
  its live vocabulary in **both** directions, so a new member fails a test and
  a rename cannot leave an entry behind describing a name that is gone.
  `unit` and `default` are the schemas' own; `typical` is the only authored
  field. Two departures from the WP's design line, both measured: a row carries
  `help_key`, the family glob, rather than the entry, because inlining an entry
  repeats a paragraph once per atom (3.4× the `/api/params` payload, 20.8 kB →
  70.0 kB on the NAC example, against 40.7 kB for the whole registry fetched
  once); and it is filled in `Refinement.parameters` rather than in the GUI
  session, so `None` means "no family claims this path" for every caller
  instead of "nobody looked". Three of the WP's own findings were wrong and the
  live vocabulary corrected them: `extinction` is a bare scalar,
  `preferred_orientation.r` is missing from the committed fnmatch corpus (whose
  two models carry no PO block, so it cannot be the coverage authority), and a
  third table path renaming existed that nobody had found — an ADP component
  loses its `aniso` segment — surfaced only because the test asserts its rename
  map is exhaustive. The manual gained a glossary generated at build time, and
  every entry's anchor is checked against the built HTML rather than the
  sources. Next: WP-1203.
- **2026-08-25** — [1204](../wp/1204-developer-mode-example-projects.md)
  shipped: developer mode, and three example projects in the wheel. The
  finding underneath both halves is that **opening a project already writes to
  it** — `Project.open` appends a head annotation to `history.jsonl` before any
  verb is called — so there was no read-only way to look at one, and every
  developer poking at a checked-in project dirtied it. `rietx gui --scratch`
  opens a byte-for-byte copy in a temp dir and names the *source* in the boot
  line; `--state-dir` exposes what only the tests could reach; the wizard's
  suggested path left the working directory, whose stated argument ("the only
  place a user has already pointed at") holds for someone who typed the command
  there and fails for a checkout. The examples are the empty state's second
  list, and each one **is** a `viz/compare.py` standard, so a protocol is never
  restated and `list_examples()` is that registry filtered by what shipped.
  What shrank the plan was a licence, not a size: `qarr/*.prn` carry no
  explicit licence and are already out of the sdist, so the four round-robin
  pure phases cannot ship, and fluorapatite had to be *created* as a standard —
  mirroring `test_acceptance_fap` field for field — to give the set a third
  specimen. `Standard` gained `pattern` and `reader_options` on the way, because
  "which file is the measurement" was a convention and a pdCIF's block choice
  changes the pattern. Measured: wheel 2.20 → 2.79 MB, examples 2.90 MB
  uncompressed; +39 python tests, +3 vitest. The browser again found what jsdom
  cannot: `.pick` gives up its box because the row is the target, so a list that
  gives the row no hover reads as prose that happens to be clickable. Next:
  WP-1202/1203.
