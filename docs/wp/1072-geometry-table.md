## Goal

A converged result carries a bonding-geometry table — distances and angles,
bonding and nonbonding contacts, symmetry codes — with esds propagated
through the **full** parameter covariance, and the CIF export writes the
`_geom_` loops. Gap 4 of the McCusker audit (`../milestones/v1.0.md`
§ Appendix).

## Context

- **The paper's second "most important criterion"** for judging a Rietveld
  refinement (§11) is that the distances and angles are chemically sensible
  — and §10 requires derived-quantity esds to use the whole correlation
  matrix, not the diagonal. Today the result reports *restrained* distances
  only, without esds, so §10's rule has nothing to apply to in geometry.
- **Reuse, don't re-derive.** `model/restraints.py` already computes bond
  distances and angles from fractional coordinates plus the cell
  (`_bond_distance`, `_bond_value_np`), and `_bond_row_partials` implements
  the exact derivative chain a geometry esd needs — through the coordinate
  DOFs' affine ties (p = C·θ + d, WP-0301) *and* the cell parameters.
  `qpa.weight_fractions` is the propagation precedent: J·Cov·Jᵀ, with the
  diagonal-only value returned beside it so the difference is visible — do
  the same here, it is the §10 lesson made measurable.
- **The covariance is never serialized.** It is read off the final Jacobian
  (the WP-1055/1056 carrier argument), so the table is computed at fit close
  and carried on the result — a field that cannot be recomputed from the
  stored result, the `Identifiability` precedent. A replayed or loaded
  result carries what was stored or `None`, never a silent diagonal-only
  recomputation.
- **Neighbours across symmetry.** Bonded pairs come from a covalent-radius
  cutoff and contacts from a documented distance cutoff, searched across
  symmetry images and cell translations — gemmi's neighbour search is the
  candidate (gemmi is already the symmetry dependency; verify its API
  rather than hand-rolling). A pair generated by an operation R carries R
  into the derivative chain (the parent atom's DOFs act through the op), and
  the CIF loop wants the standard symmetry code for it.
- **Tensor trap check**: distances contract coordinates with the metric G,
  not hkl — the untransposed-rotation rule (`wyckoff.adp_basis`'s side of
  the Rᵀ invariant) applies to anything that transforms like the metric.
  Assert a symmetry-generated bond's length and esd equal its parent's,
  which only holds when the op is applied on the correct side.
- Angles at every atom shared by two bonded pairs; the esd chain is the same
  machinery through `_bond_value_np`'s angle branch.
- CIF: `_geom_bond_distance` / `_geom_angle` loops with esds and symmetry
  codes — verify tag spellings against the dictionary, as WP-1069 does.
- Additive defaulted result field; no version bump (events precedent).

## Non-goals

- Torsion angles (the paper does not ask; record as a possible follow-up).
- Auto-generating restraints from the table.
- Any judgement of "sensible" — the table is evidence for the reader (and
  the report may later cite it; that is a FitReport WP, not this one).
- Difference Fourier maps (v2+ fence).

  **Three decisions worth knowing before touching this.**

  1. **The listing rule is "every atom's whole environment", not the CIF's.**
     A two-site bond is in the table twice, once from each end, so the row
     count naming an atom *is* its coordination number; the exporter drops one
     direction because a CIF lists a bond once and a per-atom sum would
     double-count. The first attempt deduplicated same-site pairs by mapping
     each image S to S⁻¹ — that map is only an involution when the site
     symmetry is trivial, and it silently dropped real neighbours while every
     distance-value test still passed. **Orbit counting is what caught it**
     (|A_ij|·m_i = |A_ji|·m_j) and is now a parametrised test.
  2. **Three esd cases report `None`, and they are not the same thing said
     three ways.** No covariance at all (evaluate-only); no free source (an
     all-zero block, `weight_fractions`' rule); a quadratic form that reaches
     zero by cancelling across a tie, which is roundoff and is caught by a
     *self-scaling* test — var against Σ|terms|, `VARIANCE_CANCELLATION_FLOOR`
     — rather than an absolute floor. A fourth, the straight angle, is
     separate: there the linearisation itself fails, and the limit is
     **derived** from `restraints._COS_CLAMP` so the two cannot drift.
  3. **Metal–metal pairs are demoted to contacts.** Cordero radii plus the CSD
     0.4 Å slack make corundum's Al···Al at 2.65 and 2.79 Å "bonds" (the sum is
     2.82), which then become arms of 30 spurious angles. The distances are
     still reported; only the loop changes.

  **Gotchas for the next session.** `format_su` will happily print
