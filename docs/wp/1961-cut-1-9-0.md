## Context

**Why this cut is early.** 1.8.0 was tagged 2026-10-12 on `56427c4a`, so the
weekly date is about 2026-10-19. The maintainer asked on 2026-10-14 for the
cut to come sooner, for two reasons from WP-1957.
- The landing page's Jupyter quickstart lists the notebooks at the newest
  `v*` tag (WP-1917). Template notebook 06 merged after v1.8.0, so it has no
  row until a tag carries it.
- 1.8.0's notebook figures declare both width and height, the metadata
  WP-1957 replaced as the likely cause of figures squashed in Colab. A Colab
  notebook installs the release, so only the release carries the fix there.

Measured 2026-10-14, by WP-1957's handover: 06 runs top to bottom on rietx
1.8.0 from PyPI. So nothing about the template depends on code that is not yet
released.

**The trigger was WP-1959, and its kernel wheel.** The maintainer wanted 1959
merged first. 1959 adds a kernel, so its tasks shipped `rietx-kernels` 1.3.0
and raised rietx's floor to it. A rietx 1.9.0 whose floor names a kernel wheel
PyPI does not have cannot be installed. Both halves landed on 2026-10-14:
- `rietx-kernels` 1.3.0 is on PyPI (tag `kernels-v1.3.0` on `2cbd7363`), with
  the same five wheels as 1.2.0. It installs from the index in a fresh venv.
- #971 raised the pin's floor from 1.1 to 1.3 and merged as `ec9ddda7`. It
  added the notes' "Requirements that rise" section and dropped the dichotomy
  bullet's older-wheel sentence.

**The range at the open.** `v1.8.0..e66fb223`: 219 non-merge commits and 31
pull requests. The staged notes and the v1.9 record have been written into by
each session that landed a change since 2026-10-12. The audit runs on the tree
at open, and runs again over whatever merges before the version bump.

**The nightly at the open.** The 2026-10-13 nightly (`0ba8df81`) had the three
gate jobs green: Windows and the Linux fast suite on Python 3.12 and 3.13. The
`full` job has been red on four nightlies running (`0f30d584`, `dd20f0fd`,
`56427c4a`, `0ba8df81`), on one test:
`test_acceptance_lab6_cbn.py::test_the_correlation_diagnostic_separates_the_two`.
WP-1930's #925 is the fix (merged 2026-10-13 15:35 UTC, `21915060`). Its
handover measured the guard firing at all ten start nudges. No nightly has run
on a tree holding it yet. The `full` job is read here and does not gate
(`RELEASING.md` step 4).
