# WP-1532 — the skill passages a driving agent needed: fourteen rows, placed where each is cheapest

Milestone: unscheduled · Status: ⬜
Track: The repo's own process
Depends on: — (PR #660 soft: the docstring and diagnostic-text half of the same findings)

## Goal

Each of the fourteen passages issue #661 proposes is either in the skill, in
the package's own output, or declined with a reason, and the skill's size
caps still pass.

## Context

Issue #661 (mustachefeeling, 2026-10-01) lists fourteen places where an agent
driving rietx only through its installed skill went the wrong way, while
comparing rietx against an independent refinement program. Each row carries
its exact proposed wording and how it was checked on `d6153e12`. The issue is
the wording's authority; this file does not copy it. The rows, by file:

- `SKILL.md`: the σ floor after PR #657; matching another program's
  background order (`background_terms`); f′/f″ above 70 keV and
  `dispersion = None`; the TCHZ bound boxes per preset; two starts giving two
  basins; `RESOLUTION_NOT_POSITIVE` being revisable.
- `references/api.md` (generated by `docs/skill/make_api_index.py`): a
  reflection table without a fit (`run_stage` with `turn_on=[]`,
  `max_iter=0`); a coordinate DOF reading 0 after a fit; flattened
  background paths.
- `references/diagnostics-projects.md`: a TOPAS-to-rietx mapping table; the
  limit of `coverage.partial == False` (see WP-1530); the
  `TOPAS_BLOCK_SKIPPED` clause if PR #660 merges.
- `references/diagnostics.md`: the origin-choice suffix under
  `SPACE_GROUP_SETTING_ASSUMED`; isotope spellings for neutron species.

**The issue's byte arithmetic is wrong, and that decides the work.** It
counts `SKILL.md`'s headroom under `SKILL_MAX_BYTES` (30 682 of 33 000 B).
The body is also under `SKILL_BUDGET_BYTES` = 17 000 B, the spec's
5 000-token recommendation, and sits over it at 29 740 B. That budget is a ratchet
(`tests/skill_caps.py`): while over, no change may grow the body, so every
body sentence must be paid for by a cut. And WP-1338's placement rule puts a
feature's guidance in the cheapest place that holds it: the package's own
output first (`Diagnostic.suggestion`, `help.py`), then a reference row keyed
by a name the agent already holds, and the body last. Most of the six body
rows have such a name (`DISPERSION_NEGLECTED`, `RESOLUTION_NOT_POSITIVE`,
`ProfileTCHZ`, `background_terms`). `references/api.md` is at 39 349 of
`API_INDEX_MAX_BYTES` = 39 500 B, so its three rows need a trim or a cap
decision. The issue offers `diagnostics-projects.md` (20 260 B) as the
alternative home.

Checked in the 2026-10-02 triage at `ca9bda29`: a 0.1665 Å Si model raises
"outside the tabulated 3-70 keV band" on `predict`, and `reflection_table()`
on a fresh `Refinement` raises "call fit() first". `Atom(species="Li7")`
constructs, so the refusal the issue quotes happens later, at evaluation.
The row needs that check before it is written.

### Inherited
